# 주간보고 변환기 v1.1 (Chrome) — 설치·사용 매뉴얼 (대리자용)

## 하는 일
취합이 끝난 `[취합중] 주간업무보고_…docx`에서 **빨간색** 내용만 뽑아 임원회의용 양식(hwpx)에 넣고, 확인할 것을 알려 줍니다. 파일은 PC 안에서만 처리되며 인터넷으로 보내지 않습니다. 오탈자·문맥 검토는 하지 않습니다(담당자/AI 검토 단계).

## 설치 (1회, 2분)
1. `weekly-report-converter-extension.zip`을 압축 해제 → `weekly-report-converter-extension` 폴더가 생깁니다(지우지 말고 그대로 둡니다. 예: `C:\Tools\weekly-report-converter-extension`).
2. Chrome 주소창에 `chrome://extensions` 입력 → 오른쪽 위 **개발자 모드** 켜기.
3. **압축해제된 확장 프로그램을 로드합니다** 클릭 → 1)의 폴더 선택.
4. 주소창 오른쪽 퍼즐(🧩) 아이콘 → "주간보고 변환기" 핀(📌) 고정.
   - 개발자 모드가 회사 정책으로 막혀 있으면: `weekly-report-converter.html` 파일을 Chrome으로 열어(더블클릭) 똑같이 쓰면 됩니다. 설치가 필요 없습니다.

## 순서 (5분)
1. 툴바의 변환기 아이콘 클릭(또는 `weekly-report-converter.html` 열기).
2. **[폴더 선택…]** → 주간업무보고 폴더(취합본 docx와 `…양식.hwpx`가 있는 폴더) 선택 → "파일 보기/변경 허용" 클릭.
   - 다음부터는 **[최근 폴더 다시 열기]** 한 번이면 됩니다.
   - 취합본·양식·보고일이 자동으로 잡힙니다. 취합본이 여러 개면 목록에서 고릅니다.
3. **[변환]** 클릭. 같은 폴더에 생깁니다.
   - `[임원회의용] 연구본부 주간업무보고(YYMMDD).hwpx` ← 송부 파일 (같은 이름이 있으면 `_v2`)
   - `변환결과_YYMMDD.html` ← 확인할 것 목록 / `_로그\변환_….json` ← 담당자 확인용
4. 화면의 **확인할 것(오류/경고)**를 읽고, 작성 부서 확인이 필요한 것(요일 불일치 등)은 확인 후 docx를 고쳐 **다시 변환**.
5. 한글에서 hwpx를 열어 **쪽 수, 표 셀 넘침, 줄 끝 어절 분리**를 눈으로 확인한 뒤 기획조정팀에 송부.

## 프로그램이 자동으로 하는 것 (손대지 않아도 됨)
항목 번호 1부터 재부여 · 칸 없는 부서(연구지원팀)는 '연구본부' 제목 아래 · 항목 사이 빈 줄 · 한 쪽(약 30행) 넘으면 같은 표를 복제해 다음 쪽으로 항목 넘김(항목 중간에서 안 나눔) · 빨간색 표는 표로 변환 · 표지 날짜·실적/계획 기간·수입실적·월간계획 월 자동 입력 · 글꼴·자간·장평 통일.

## 송부 전 체크리스트
- [ ] 화면에 **오류** 0건(있으면 작성 부서 확인 완료)
- [ ] 한글에서 쪽 수 확인, 셀 넘침·잘린 줄 없음
- [ ] 수입실적 3개 숫자가 취합본과 같음
- [ ] 파일명 날짜 = 임원회의 날짜(YYMMDD)

담당자 부재 시: `_로그` 최신 파일과 취합본을 함께 보내면 원격으로 확인 가능.
